- 하자/오배송은 판매자 부담으로 하고, 표시·광고/계약과 다른 경우의 3개월·인지 후 30일 기준과 다른 하자 권리를 보존합니다. 이 기간을 모든 품질보증의 종료일로 사용하지 않습니다.

- 일반 가구에 주문제작 예외를 적용하지 않았습니다. 맞춤제작 문의와 실제 주문제작 판매의 사전 별도 동의는 구분했습니다.
- 개인정보처리방침 공개와 필수 수집·이용 동의를 구분했습니다. 실제 최소 수집·처리 근거, 마케팅 목적 이용과 광고 수신 동의의 구분·표시 방법, 위탁/국외 이전 고지는 최종 공개 전 전문가 검토가 필요합니다.

## 결제 기능 도입 시 갱신

실제 선택한 PG/간편결제 제공자의 법인명·수탁/제공 관계, 처리 목적·항목·보유기간·재위탁·국외 이전을 확인합니다. 구매자·수령인·주문·결제승인·취소/환급 데이터 중 자사몰이 실제로 보유하는 항목을 추가합니다. 카드정보를 PG만 처리한다면 그루잠도 카드번호를 직접 저장한다고 기재하지 않습니다.

주문 정보와 회원 탈퇴를 분리하고 법정 거래기록의 보존·파기, 비회원 주문 시 안내, 실제 배송업체 제공/위탁, 주문 알림 발송 업체, 현금영수증/환급 절차 등을 구현 범위에 맞춰 갱신합니다. 현금영수증 식별번호나 환급 계좌도 실제 수집을 결정하기 전에는 현재 항목으로 추가하지 않습니다. 개인정보 처리와 별도로 결제수단, 구매계약 승낙 시점, 공급·환급 절차, 구매안전서비스 적용 여부 등 거래 전 표시 사항을 점검합니다.
